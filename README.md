# Fruit Fly Drone

**Connectome-Inspired Autonomous Navigation Simulator**

A browser-based 3D autonomous robotics research prototype exploring whether brain-inspired neural architectures based on the *Drosophila* (fruit-fly) connectome can be used for autonomous navigation.

> **Vibe-Coded Build**
>
> This repository is an early experimental prototype built primarily through rapid AI-assisted ("vibe-coded") development. It is intended for testing ideas, exploring the architecture, and validating the initial concept — **not a finished research implementation or production-ready simulator**.
>
> The current implementation may contain simplified models, incomplete components, experimental code, and temporary implementations. The architecture and approach are expected to change significantly as the project develops.
>
> The long-term goal is to replace the initial experimental components with properly validated simulation, neural, and connectome-derived implementations and evaluate them through reproducible experiments.
